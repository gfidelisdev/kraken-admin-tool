# Host Port Auditor Plugin

Este plugin audita portas de rede abertas nos servidores e containers gerenciados pelo Kraken Admin Tool.

## Recursos
- Identificação de portas de risco (22, 23, 80, 443, 3306, 5432, 6379, 27017, 8080)
- Integração nativa na Sidebar do Kraken
- Widget no painel de Overview
- Execução segura e isolada via Web Worker Sandbox e WASM
